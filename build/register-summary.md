# ISO JAG Building Blocks register

This is an example to illustrate the use of OGC Building Blocks.


## Building Blocks

### `iso.bbr.sample.jag.mySchema` — My Schema

**Type:** schema

An example schema defining the set of properties of any type of object.

### `iso.bbr.sample.jag.myFeature` — Custom Feature

**Type:** schema

This examples shows a simple customisation for OGC API Feature schemas
